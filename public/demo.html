CLI Tool Integration

Generate optimized CDN links directly from your terminal using the GitDelivr NPM package.

Step 1: Global Installation

Install the GitDelivr CLI tool globally via NPM to access it from anywhere in your system:

$ npm install -g gitdelivr-cli

Step 2: Generate Links

Run the gitdelivr command followed by the GitHub repository and file path:

$ gitdelivr generate gitdelivr/demo main src/app.js

> Fetching file details from GitHub API...
> GitDelivr CDN Link:
https://cdn.gitdelivr.in/gh/gitdelivr/demo@main/src/app.js

✔ Successfully copied to clipboard!

Available Commands

The CLI supports multiple operations for different providers (NPM, GitLab, WordPress):

$ gitdelivr --help

Commands:
  generate <repo> <branch> <file>   Generate a standard GitHub CDN link
  npm <package> <file>              Generate an NPM registry link
  sri <url>                         Calculate Subresource Integrity hash
  purge <url>                       Clear edge cache for a specific URL

Native CORS Bypass

NPM & WP Support

SRI Hash Generation

Generates Subresource Integrity (SHA-384) hashes instantly to ensure your files are never tampered with.

Chunked Media Streaming

Perfectly supports byte-range requests (206 Partial Content) for zero-buffering video and audio playback.

MIME Type Correction

Fixes GitHub's text/plain problem. JS, CSS, and media are served with their proper executable MIME types.

How to Use SRI Hashes

Using SRI is easy. Just add the integrity and crossorigin attributes to your HTML tags.

Example 1: JavaScript

<script src="https://cdn.gitdelivr.in/gh/user/repo@main/app.js"
        integrity="sha384-oqVuAfXRRu7n041F2ZOsHw..."
        crossorigin="anonymous"></script>

Example 2: CSS Stylesheet

<link rel="stylesheet" href="https://cdn.gitdelivr.in/gh/user/repo@main/style.css"
      integrity="sha384-xyz123..."
      crossorigin="anonymous">

Example 3: Video/Audio Media

<video controls preload="metadata"
       integrity="sha384-abc987..."
       crossorigin="anonymous">
  <source src="https://cdn.gitdelivr.in/gh/user/repo@main/video.mp4">
</video>
